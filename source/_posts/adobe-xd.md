## Atalhos de teclado

### Teclas do menu Editar

| Atalho             | Ação                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| `Ctrl` `Z`         | Desfazer                                                              |
| `Ctrl` `Shift` `Z` | Refazer                                                               |
| `Ctrl` `X`         | Recortar                                                              |
| `Ctrl` `C`         | Copiar                                                                |
| `Ctrl` `V`         | Colar                                                                 |
| `Ctrl` `Alt` `V`   | Cola aparência (modo Design) ou cola interação (modo Prototype)       |
| `Ctrl` `D`         | Duplicar                                                              |
| `Del`              | Excluir                                                               |
| `Ctrl` `A`         | Selecionar tudo                                                       |
| `Ctrl` `Shift` `A` | Desmarcar tudo                                                        |

{.shortcuts}
