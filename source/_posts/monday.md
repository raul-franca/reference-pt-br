## Atalhos de Teclado

### Sistema

| Atalho     | Ação                                          |
| ---------- | --------------------------------------------- |
| `Ctrl` `B` | Bolt Switch (alternância rápida entre boards) |
| `Esc`      | Fechar página do item                         |
| `Esc`      | Fechar diálogos                               |
| `Esc`      | Fechar pesquisa                               |

{.shortcuts}

### Board I

| Atalho        | Ação                          |
| ------------- | ----------------------------- |
| `Down`        | Navegar para baixo            |
| `Up`          | Navegar para cima             |
| `Left`        | Navegar para a esquerda       |
| `Right`       | Navegar para a direita        |
| `Tab`         | Navegar para a próxima célula |
| `Shift` `Tab` | Navegar para a aba anterior   |
| `Enter`       | Editar conteúdo da célula     |
| `Backspace`   | Limpar conteúdo da célula     |
| `Space`       | Abrir visualização da coluna  |

{.shortcuts}

### Board II

| Atalho             | Ação                              |
| ------------------ | --------------------------------- |
| `Ctrl` `F`         | Pesquisar no board                |
| `Ctrl` `C`         | Copiar conteúdo da célula         |
| `Ctrl` `V`         | Colar conteúdo da célula          |
| `Ctrl` `X`         | Recortar conteúdo da célula       |
| `Ctrl` `Enter`     | Selecionar item                   |
| `Shift` `Enter`    | Selecionar intervalo de itens     |
| `Ctrl` `Shift` `G` | Criar novo grupo                  |
| `Ctrl` `Shift` `C` | Criar nova coluna                 |
| `Ctrl` `L`         | Abrir log de atividades           |
| `Ctrl` `(click)`   | Ordenar outra coluna              |
| `Ctrl` `G`         | Recolher/expandir todos os grupos |

{.shortcuts}
