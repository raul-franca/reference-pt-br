## Atalhos de teclado

### Ações

| Atalho         | Ação                    |
| -------------- | ----------------------- |
| `N`            | Novo tweet              |
| `L`            | Curtir tweet            |
| `R`            | Responder ao tweet      |
| `T`            | Retweet                 |
| `M`            | Mensagem direta         |
| `U`            | Silenciar conta         |
| `B`            | Bloquear conta          |
| `Enter`        | Abrir detalhes do tweet |
| `O`            | Expandir fotos          |
| `/`            | Pesquisar               |
| `Ctrl` `Enter` | Enviar tweet            |

{.shortcuts}

### Navegação

| Atalho  | Ação                     |
| ------- | ------------------------ |
| `?`     | Menu completo de teclado |
| `J`     | Próximo tweet            |
| `K`     | Tweet anterior           |
| `Space` | Descer uma página        |
| `.`     | Carregar novos tweets    |

{.shortcuts}
