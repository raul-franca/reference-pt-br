## Atalhos de Teclado

### Edição {.row-span-2}

| Atalho              | Ação                                                                     |
| :------------------ | :----------------------------------------------------------------------- |
| `Ctrl` `Alt` `I`    | Redimensionar documento                                                  |
| `Ctrl` `Alt` `C`    | Redimensionar canvas                                                     |
| `.`                 | Redefinir caixa de seleção                                               |
| `;`                 | Alternar snapping                                                        |
| `Ctrl`              | Apagar com a ferramenta de pixel na camada atual                         |
| `X`                 | Alternar entre seletores de cor de traço/preenchimento                   |
| `Shift` `X`         | Trocar seletores de cor de traço/preenchimento                           |
| `/`                 | Definir sem preenchimento nos seletores de cor de traço/preenchimento    |
| `O`                 | Alternar entre sobreposições da ferramenta de corte                      |
| `Shift` `O`         | Inverter sobreposição de espiral áurea (ferramenta de corte habilitada)  |
| `Esc`               | Cancelar uma operação de redimensionamento, movimentação ou criação      |
| `(arrows)`          | Mover item                                                               |
| `Shift` `(arrows)`  | Mover item em unidades de medida de 10x                                  |
