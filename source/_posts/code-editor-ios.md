## Atalhos de teclado {.cols-2}

### Atalhos gerais I

| Atalho            | Ação                                                      |
| ----------------- | --------------------------------------------------------- |
| `Esc`             | Mostra as sugestões                                       |
| `Tab`             | Insere recuo, conforme a preferência por tabs ou espaços  |
| `Cmd` `N`         | Nova aba de documento                                     |
| `Cmd` `W`         | Fecha a aba                                               |
| `Cmd` `S`         | Salva                                                     |
| `Cmd` `Z`         | Desfaz                                                    |
| `Cmd` `Shift` `Z` | Refaz                                                     |
| `Cmd` `A`         | Seleciona tudo                                            |
| `Cmd` `X`         | Recorta                                                   |
| `Cmd` `C`         | Copia                                                     |
| `Cmd` `V`         | Cola                                                      |
| `Cmd` `F`         | Localiza                                                  |
| `Cmd` `G`         | Localiza o próximo                                        |
| `Cmd` `Shift` `G` | Localiza o anterior                                       |
| `Cmd` `/`         | Alterna comentário                                        |
| `Cmd` `[`         | Aumenta o recuo da seleção                                |
| `Cmd` `]`         | Remove o recuo da seleção                                 |
| `Cmd` `Shift` `[` | Move para a aba anterior                                  |
| `Cmd` `Shift` `]` | Move para a próxima aba                                   |
| `Cmd` `4`         | Alterna a pré-visualização, somente no editor             |
| `Cmd` `K`         | Limpa o scrollback, somente no terminal e nos playgrounds |

{.shortcuts}

### Atalhos gerais II

| Atalho                      | Ação                                    |
| --------------------------- | --------------------------------------- |
| `Cmd` `R`                   | Recarrega, somente na pré-visualização  |
| `Cmd` `Left`                | Volta, somente na pré-visualização      |
| `Cmd` `Right`               | Avança, somente na pré-visualização     |
| `Shift` `Left`              | Seleciona o caractere anterior          |
| `Shift` `Right`             | Seleciona o próximo caractere           |
| `Cmd` `Left`                | Move para o início da linha atual       |
| `Cmd` `Right`               | Move para o fim da linha atual          |
| `Cmd` `Shift` `Left`        | Seleciona até o início da linha atual   |
| `Cmd` `Shift` `Right`       | Seleciona até o fim da linha atual      |
| `Opt` `Left`                | Move para o início da palavra atual     |
| `Opt` `Right`               | Move para o fim da palavra atual        |
| `Opt` `Shift` `Left`        | Seleciona até o início da palavra atual |
| `Opt` `Shift` `Right`       | Seleciona até o fim da palavra atual    |
| `Cmd` `Del`                 | Apaga até o início da linha atual       |
| `Cmd` `Opt` `Del`           | Apaga até o início da palavra atual     |
| `Cmd` `Del (forward)`       | Apaga até o fim da linha atual          |
| `Cmd` `Opt` `Del (forward)` | Apaga até o fim da palavra atual        |
| `Ctrl` `A`                  | Move para o início da linha atual       |
| `Ctrl` `Shift` `A`          | Seleciona até o início da linha atual   |
| `Ctrl` `E`                  | Move para o fim da linha atual          |
| `Ctrl` `Shift` `E`          | Seleciona até o fim da linha atual      |
| `Ctrl` `K`                  | Apaga até o fim da linha atual          |
