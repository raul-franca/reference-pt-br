## Atalhos de teclado

### Compor e conversar

| Atalho             | Ação                                     |
| ------------------ | ---------------------------------------- |
| `P`                | Mensagem anterior em uma conversa aberta |
| `N`                | Próxima mensagem em uma conversa aberta  |
| `Shift` `Esc`      | Foca a janela principal                  |
| `Esc`              | Foca o chat ou a composição mais recente |
| `Ctrl` `.`         | Avança para o próximo chat ou composição |
| `Ctrl` `,`         | Avança para o chat ou composição anterior |
| `Ctrl` `Enter`     | Enviar                                   |
| `Ctrl` `Shift` `C` | Adiciona destinatários em cópia (cc)     |
| `Ctrl` `Shift` `B` | Adiciona destinatários em cópia oculta (bcc) |
| `Ctrl` `Shift` `F` | Acessa o campo "De" personalizado        |
| `Ctrl` `K`         | Insere um link                           |
| `Cmd` `;`          | Vai para a próxima palavra escrita incorretamente (somente Mac) |
| `Ctrl` `M`         | Abre as sugestões ortográficas           |

{.shortcuts}

### Formatação de texto

| Atalho             | Ação               |
| ------------------ | ------------------ |
| `Ctrl` `Shift` `5` | Fonte anterior     |
| `Ctrl` `Shift` `6` | Próxima fonte      |
| `Ctrl` `Shift` `-` | Diminui o tamanho da fonte |
| `Ctrl` `Shift` `+` | Aumenta o tamanho da fonte |
| `Ctrl` `B`         | Negrito            |
| `Ctrl` `I`         | Itálico            |
| `Ctrl` `U`         | Sublinhado         |
| `Ctrl` `Shift` `7` | Lista numerada     |
| `Ctrl` `Shift` `8` | Lista com marcadores |
| `Ctrl` `Shift` `9` | Citação            |
| `Ctrl` `[`         | Diminui o recuo    |
| `Ctrl` `]`         | Aumenta o recuo    |
| `Ctrl` `Shift` `L` | Alinha à esquerda  |
| `Ctrl` `Shift` `E` | Centraliza         |
| `Ctrl` `Shift` `R` | Alinha à direita   |
| `Ctrl` `\`         | Remove a formatação |

{.shortcuts}

### Ações {.row-span-2}

| Atalho      | Ação                                                  |
| ----------- | ----------------------------------------------------- |
| `,`         | Move o foco para a barra de ferramentas               |
| `X`         | Seleciona a conversa                                  |
| `S`         | Alterna a estrela ou alterna entre as superestrelas   |
| `E`         | Arquivar                                              |
| `M`         | Silencia a conversa                                   |
| `Shift` `1` | Denuncia como spam                                    |
| `Shift` `3` | Excluir                                               |
| `R`         | Responder                                             |
| `Shift` `R` | Responde em uma nova janela                           |
| `A`         | Responder a todos                                     |
| `Shift` `A` | Responde a todos em uma nova janela                   |
| `F`         | Encaminhar                                            |
| `Shift` `F` | Encaminha em uma nova janela                          |
| `Shift` `N` | Atualiza a conversa                                   |
| `]/[`       | Arquiva a conversa e vai para a anterior ou a próxima |
| `Z`         | Desfaz a última ação                                  |
| `Shift` `I` | Marca como lida                                       |
| `Shift` `U` | Marca como não lida                                   |
| `Shift` `-` | Marca como não lida a partir da mensagem selecionada  |
| `=`         | Marca como importante                                 |
| `-`         | Marca como não importante                             |
| `B`         | Adiar                                                 |
| `;`         | Expande toda a conversa                               |
| `Shift` `;` | Recolhe toda a conversa                               |
| `Shift` `T` | Adiciona a conversa às tarefas                        |

### Ir para

| Atalho             | Ação                                                                 |
| ------------------ | -------------------------------------------------------------------- |
| `G` `I`            | Vai para a caixa de entrada                                          |
| `G` `S`            | Vai para as conversas com estrela                                    |
| `G` `B`            | Vai para as conversas adiadas                                        |
| `G` `T`            | Vai para as mensagens enviadas                                       |
| `S` `D`            | Vai para os rascunhos                                                |
| `G` `A`            | Vai para todos os e-mails                                            |
| `Ctrl` `Alt` `,/.` | Alterna entre a barra lateral de agenda, keep e tarefas e a caixa de entrada |
| `G` `K`            | Vai para as tarefas                                                  |
| `G` `L`            | Vai para o marcador                                                  |

{.shortcuts}

### Seleção da lista de conversas

| Atalho          | Ação                            |
| --------------- | ------------------------------- |
| `Shift` `8` `A` | Seleciona todas as conversas    |
| `Shift` `8` `N` | Desmarca todas as conversas     |
| `Shift` `8` `R` | Seleciona as conversas lidas    |
| `Shift` `8` `U` | Seleciona as conversas não lidas |
| `Shift` `8` `S` | Seleciona as conversas com estrela |

{.shortcuts}

### Navegação

| Atalho                  | Ação                          |
| ----------------------- | ----------------------------- |
| `G` `N`                 | Vai para a próxima página     |
| `G` `P`                 | Vai para a página anterior    |
| `U`                     | Volta para a lista de conversas |
| `K`                     | Conversa mais recente         |
| `J`                     | Conversa mais antiga          |
| `Enter`                 | Abre a conversa               |
| <code>\`</code>         | Vai para a próxima seção da caixa de entrada |
| `Shift` <code>\`</code> | Vai para a seção anterior da caixa de entrada |

{.shortcuts}

### Aplicativo

| Atalho | Ação                          |
