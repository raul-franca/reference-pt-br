## Atalhos de Teclado {.cols-2}

### Editor I

| Atalho            | Ação                                         |
| ----------------- | -------------------------------------------- |
| `Ctrl` `C`        | Copia                                        |
| `Ctrl` `V`        | Cola                                         |
| `Ctrl` `A`        | Seleciona tudo                               |
| `Ctrl` `X`        | Recorta                                      |
| `Ctrl` `Z`        | Desfaz                                       |
| `Ctrl` `Y`        | Refaz                                        |
| `Ctrl` `B`        | Negrito                                      |
| `Ctrl` `I`        | Itálico                                      |
| `Ctrl` `U`        | Sublinhado                                   |
| `Ctrl` `K`        | Insere ou edita um link                      |
| `Alt` `Shift` `N` | Verifica a ortografia, isso requer um plugin |
| `Alt` `Shift` `L` | Alinha o texto à esquerda                    |
| `Alt` `Shift` `J` | Justifica o texto                            |
| `Alt` `Shift` `C` | Centraliza o texto                           |
| `Alt` `Shift` `D` | Tachado                                      |
| `Alt` `Shift` `R` | Alinha o texto à direita                     |
| `Alt` `Shift` `U` | Lista não ordenada                           |

### Editor II

| Atalho            | Ação                                 |
| ----------------- | ------------------------------------ |
| `Alt` `Shift` `A` | Insere um link                       |
| `Alt` `Shift` `O` | Lista ordenada                       |
| `Alt` `Shift` `S` | Remove um link                       |
| `Alt` `Shift` `Q` | Citação                              |
| `Alt` `Shift` `M` | Insere uma imagem                    |
| `Alt` `Shift` `W` | Modo de escrita sem distrações       |
| `Alt` `Shift` `T` | Insere uma tag more                  |
| `Alt` `Shift` `P` | Insere uma tag de quebra de página   |
| `Alt` `Shift` `H` | Ajuda                                |
| `Alt` `Shift` `X` | Adiciona ou remove uma tag de código |
| `Alt` `Shift` `1` | Título um                            |
| `Alt` `Shift` `2` | Título dois                          |
| `Alt` `Shift` `3` | Título três                          |
| `Alt` `Shift` `4` | Título quatro                        |
| `Alt` `Shift` `5` | Título cinco                         |
| `Alt` `Shift` `6` | Título seis                          |
| `Alt` `Shift` `9` | Insere um endereço                   |
