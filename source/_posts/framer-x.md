## Atalhos de teclado

### Ferramentas

| Atalho  | Ação        |
| ------- | ----------- |
| `F`     | Frame       |
| `U`     | Arredondar  |
| `T`     | Texto       |
| `S`     | Stack       |
| `L`     | Link        |
| `Space` | Mover a tela |

{.shortcuts}

### Gráficos

| Atalho            | Ação       |
| ----------------- | ---------- |
| `G`               | Gráfico    |
| `P`               | Caminho    |
| `R`               | Retângulo  |
| `O`               | Oval       |
| `V`               | Vetor      |
| `Cmd` `G`         | Agrupar    |
| `Cmd` `Shift` `G` | Desagrupar |

{.shortcuts}

### Layout

| Atalho              | Ação             |
| ------------------- | ---------------- |
| `Cmd` `Enter`       | Adicionar frame  |
| `Cmd` `Opt` `Enter` | Adicionar stack  |
| `Cmd` `Del`         | Remover wrapper  |
| `Cmd` `Opt` `Up`    | Mover para frente |
| `Cmd` `Opt` `Down`  | Mover para trás  |

{.shortcuts}
