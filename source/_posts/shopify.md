## Atalhos de Teclado

### Atalhos gerais

| Atalho      | Ação                    |
| ----------- | ----------------------- |
| `?`         | Ajuda de teclado        |
| `S`         | Foca a barra de pesquisa |
| `F`         | Foca a barra de filtros |
| `B` `Y` `E` | Sai da conta            |
| `M` `E`     | Seu perfil              |
| `O` `S`     | Abre o seletor de lojas |
