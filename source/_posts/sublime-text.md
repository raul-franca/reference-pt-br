## Atalhos de teclado

### Edição {.row-span-3}

| Atalho                 | Ação                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------- |
| `Ctrl` `X`             | Recortar linha                                                                          |
| `Ctrl` `Enter`         | Inserir linha depois                                                                    |
| `Ctrl` `Shift` `Enter` | Inserir linha antes                                                                     |
| `Ctrl` `Shift` `Up`    | Mover linha/seleção para cima                                                           |
| `Ctrl` `Shift` `Down`  | Mover linha/seleção para baixo                                                          |
| `Ctrl` `L`             | Selecionar linha - Repita para selecionar as próximas linhas                            |
| `Ctrl` `D`             | Selecionar palavra - Repetir seleciona outras ocorrências                               |
| `Ctrl` `M`             | Ir para o parêntese de fechamento - Repita para ir ao parêntese de abertura             |
| `Ctrl` `Shift` `M`     | Selecionar todo o conteúdo dos parênteses atuais                                        |
| `Ctrl` `Shift` `K`     | Excluir linha                                                                           |
| `Ctrl` `K, K`          | Excluir do cursor até o fim da linha                                                    |
| `Ctrl` `K` `Backspace` | Excluir do cursor até o início da linha                                                 |
| `Ctrl` `]`             | Indentar a(s) linha(s) atual(is)                                                        |
| `Ctrl` `[`             | Remover indentação da(s) linha(s) atual(is)                                             |
| `Ctrl` `Shift` `D`     | Duplicar linha(s)                                                                       |
| `Ctrl` `J`             | Juntar a linha abaixo ao final da linha atual                                           |
| `Ctrl` `/`             | Comentar/descomentar a linha atual                                                      |
| `Ctrl` `Shift` `/`     | Comentar em bloco a seleção atual                                                       |
| `Ctrl` `Y`             | Refazer ou repetir o último comando de atalho de teclado                                |
| `Ctrl` `Shift` `V`     | Colar e indentar corretamente                                                           |
| `Ctrl` `Space`         | Selecionar próxima sugestão de autocompletar                                            |
| `Ctrl` `U`             | Desfazer suave; volta à sua última alteração antes de desfazer, alterne quando repetido |
| `Alt` `Shift` `W`      | Envolver a seleção em uma tag HTML                                                      |
| `Alt` `.`              | Fechar a tag HTML atual                                                                 |
| `Alt` `Q`              | Quebrar linha forçadamente na coluna definida pela régua                                |

### Dividir janela

| `Alt` `Shift` `4`    | Dividir visualização em quatro colunas                        |
| `Alt` `Shift` `5`    | Definir visualização em grade (4 grupos)                      |
