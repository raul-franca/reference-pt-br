## Atalhos de Teclado

### Navegação

| Atalho             | Ação                       |
| ------------------ | -------------------------- |
| `Alt` `Left`       | Voltar                     |
| `Alt` `Right`      | Avançar                    |
| `Alt` `Home`       | Página inicial             |
| `Ctrl` `O`         | Abrir arquivo              |
| `Ctrl` `R`         | Recarregar                 |
| `Ctrl` `Shift` `R` | Recarregar (ignorar cache) |
| `Ctrl` `.`         | Parar                      |
