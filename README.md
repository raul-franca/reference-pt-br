# 📖 Reference - Cheat sheets para desenvolvedores

[![love](https://badgen.net/badge/make%20with/love/pink)](#)
[![Licença](https://badgen.net/badge/license/GPL-3.0/blue)](https://github.com/Fechin/reference/blob/main/LICENSE)
[![Siga-nos no Twitter](https://img.shields.io/twitter/follow/FechinLi?style=social)](https://twitter.com/FechinLi)

Reference é uma coleção de cheat sheets contribuídas por anjos do open source. Ele compartilha uma cheat sheet de
referência rápida para desenvolvedores em um layout agradável. \[ [中文版](https://github.com/jaywcjlove/reference) | ... \]

Incentivamos você a compartilhar suas próprias cheat sheets com a comunidade e tornar o Reference ainda melhor. Se
notar uma cheat sheet que possa ser melhorada, fique à vontade para enviar um [pull request](#-contributing).

## 👀 Demonstração ao vivo

Observação: o domínio original deste projeto era quickref.me, que foi adquirido por uma empresa dos EUA. Desde então,
cheatsheets.zip é o domínio principal e mantido (tudo dentro dos limites dos acordos).

Você pode ver as cheat sheets mais atualizadas ao vivo em [https://cheatsheets.zip](https://cheatsheets.zip/).

[![Referência rápida](https://cheatsheets.zip/assets/image/preview.png?9nd3)](https://cheatsheets.zip)

## 🤝 Como contribuir

Gostaríamos de agradecer por considerar uma contribuição para o Reference. Seu apoio é o que torna este projeto um
recurso de verdade. Observe que o domínio principal para acessar o conteúdo mais atualizado é
[cheatsheets.zip](https://cheatsheets.zip). Fique à vontade para
[enviar issues](https://github.com/Fechin/reference/issues/new?assignee=Fechin) e solicitações de melhorias.

Para manter a consistência, recomendamos consultar o [https://cheatsheets.zip/quickref](https://cheatsheets.zip/quickref)
ao criar ou editar cheat sheets. Para começar a desenvolver, siga estes passos:

1. Clone o repositório do GitHub `git clone https://github.com/Fechin/reference.git`
2. Instale o gerenciador de pacotes `npm` (leia o
   [guia de instalação](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm))
3. Execute `npm install` na pasta raiz para instalar as dependências.
4. Execute `npm run dev` para iniciar um servidor de desenvolvimento. Ele serve o projeto e recarrega ao vivo quando
   qualquer arquivo é alterado; depois, visite http://127.0.0.1:4000 para visualizar.
5. Envie um pull request e aguarde a revisão e o merge.

Para criar ou editar uma cheat sheet, você precisa criar ou editar um arquivo markdown em
`source/_posts/{filename}.md`. O arquivo deve incluir uma seção de front matter com o seguinte formato:

```markdown
---
title: CheatSheets
date: 2020-11-25 18:28:43
icon: icon-style
background: bg-indigo-600
tags:
categories:
- Other
  intro: This is a reference of styles that you can use on quickref cheat sheets!
---
```

Apenas os campos `title` e `intro` são obrigatórios; as demais opções podem ficar em branco.
